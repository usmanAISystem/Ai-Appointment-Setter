‎✨ Features
‎✅ Instant Lead Response: Replies to new leads from Gmail / Google Sheets instantly  
‎✅ Human-like Qualification: Qualifies leads using AI before booking  
‎✅ Auto Calendar Booking: Directly books slots into Google Calendar API  
‎✅ Smart Follow-ups: Sends automated follow-up emails via Gmail  
‎✅ Database Integration: Stores all leads in MongoDB Atlas & Google Sheets
‎

‎🛠️ Tech Stack Used
‎Workflow Automation: n8n Workflows
‎Database: MongoDB Atlas, Google Sheets
‎APIs: Google Gmail API, Google Calendar API
‎AI Agent: LangChain / Agentic AI
‎

‎⚙️ How It Works
‎New Lead arrives in Google Sheets / Gmail
‎n8n Workflow triggers the AI Agent
‎AI Agent qualifies the lead and checks Calendar availability
‎Agent books the meeting and sends confirmation email
‎All data is saved to MongoDB Atlas
‎

‎🚀 Setup
‎Clone the repo: git clone https://github.com/usmanAISystem/Ai-Appointment-Setter.git
‎Import the n8n workflow JSON file
‎Add your API keys for Gmail, Calendar, and MongoDB Atlas in n8n credentials
